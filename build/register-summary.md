# OGC CRDWG Essential Variable Blocks

OGC Building Blocks for the Climate Resilience Domain Working Group (CRDWG)
Essential Variable registry. Provides schema, semantics, and ontology for
describing and publishing Essential Climate Variables as linked data.


## Building Blocks

### `ogc.crdwg.ev-schema` — Essential Variable

**Type:** schema

Schema and JSON-LD context for defining a Climate Resilience Essential Variable.

### `ogc.crdwg.ev-ontology` — Essential Variable Ontology

**Type:** model

OWL ontology defining vocabulary terms for Essential Variable descriptions that are not covered by standard vocabularies.

### `ogc.crdwg.ev-observation` — Essential Variable Observation

**Type:** schema

A SOSA Observation Feature whose observedProperty is constrained to a CRDWG Essential Variable.
